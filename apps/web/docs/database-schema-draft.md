# Database Schema Draft

This draft describes the planned persistence model for AkademX10 XAI. Phase 2G now includes Supabase/Postgres migration drafts under `supabase/migrations`; the frontend still does not depend on a real database.

| Table | Purpose | Key Columns | Relationships | Notes |
| --- | --- | --- | --- | --- |
| users | Stores platform, company, and learner identities. | id, name, role, title, company_id, created_at, updated_at | company_id references companies.id when role is company or learner. | Roles are exactly platform, company, learner. Platform users are global. |
| companies | Stores customer company tenants. | id, name, industry, created_at, updated_at | Referenced by company-level tables through company_id. | Platform manages companies. Company users read only own tenant. |
| company_members | Connects users to company tenants. | id, company_id, user_id, member_role, created_at | company_id references companies.id; user_id references users.id. | Enables company employee and learner membership views. |
| training_templates | Stores global platform-authored training templates. | id, title, description, category, estimated_duration_min, default_state_count, skill_tags, status, created_by_user_id, version, avatar_policy | created_by_user_id references users.id. | Templates are global and not company-owned. |
| training_modules | Stores modules that belong to templates. | id, template_id, title, description, duration_min, skill_tags, status | template_id references training_templates.id. | Companies see modules through assignments. |
| training_states | Stores ordered state-machine steps for modules. | id, module_id, state_order, title, state_type, estimated_min, avatar_enabled, avatar_budget_sec, prompt, rubric, skill_tags, completion_rule | module_id references training_modules.id. | State types mirror the frontend state-machine contract. |
| company_training_assignments | Connects templates/modules to companies. | id, company_id, template_id, module_id, assigned_by_user_id, assigned_at, status | company_id references companies.id; template_id references training_templates.id; module_id references training_modules.id. | Platform creates assignments. Companies read their own assignments. |
| learner_enrollments | Connects learners to assigned company trainings. | id, company_id, learner_user_id, assignment_id, template_id, module_id, status, assigned_at, due_at, completed_at | learner_user_id references users.id; assignment_id references company_training_assignments.id. | Company manages own enrollments. Learner reads own enrollments. |
| training_sessions | Tracks learner execution of a module. | id, company_id, learner_user_id, template_id, module_id, current_state_id, completed_state_ids, status, started_at, updated_at, completed_at | learner_user_id references users.id; module_id references training_modules.id. | Sessions always include learner, module, and company context. |
| session_answers | Stores learner answers. | id, session_id, company_id, learner_user_id, state_id, answer_text, submitted_at | session_id references training_sessions.id; state_id references training_states.id. | Access follows session ownership and company scope. |
| session_feedback | Stores feedback generated for states or answers. | id, session_id, company_id, state_id, overall_score, dimensions, feedback_text, improvement_suggestion, next_action, generated_by, created_at | session_id references training_sessions.id; state_id references training_states.id. | Generated by mock logic now, AI later. |
| skill_scores | Stores normalized skill score outputs. | id, session_id, company_id, skill, score, delta, created_at | session_id references training_sessions.id. | Used by reports and dashboards. |
| session_usage | Stores aggregate usage and budget values. | id, session_id, company_id, learner_user_id, total_duration_min, avatar_target_min, avatar_toggle_target, buffered_avatar_min, avatar_used_min, avatar_open_count, estimated_avatar_cost_usd, safe_avatar_cost_usd, estimated_total_cost_usd, safe_budget_usd | session_id references training_sessions.id. | Holds Phase 0 cost summary values. |
| session_cost_logs | Stores raw metering and estimated cost logs. | id, session_id, company_id, input_tokens, output_tokens, stt_minutes, tts_characters, avatar_active_seconds, avatar_open_count, buffered_billable_avatar_min, estimated_cost_usd, metadata, created_at | session_id references training_sessions.id. | Tracks token usage, STT minutes, TTS characters, avatar active seconds, avatar open count, buffered billable duration, and estimated cost. |
| session_event_logs | Stores chronological session events. | id, session_id, company_id, learner_user_id, state_id, event_type, payload, occurred_at | session_id references training_sessions.id; state_id references training_states.id when applicable. | Event types: state_started, answer_submitted, feedback_generated, avatar_opened, avatar_closed, state_completed, session_completed. |
| reports | Stores final learner session reports. | id, session_id, company_id, learner_user_id, completion_summary, strengths, improvement_areas, action_plan, created_at | session_id references training_sessions.id; learner_user_id references users.id. | Company reads own reports. Learner reads own reports. |

## Tenant Rules

Every company-level table includes company_id where appropriate. Platform templates are global. Assignments connect global training content to companies. Enrollments connect learners to company-assigned training. Sessions, answers, feedback, scores, usage, cost logs, event logs, and reports are company-scoped and learner-owned where applicable.
